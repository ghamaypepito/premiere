# AI visibility prompt panel (30 prompts)

This panel feeds the AEO section of each monthly report. Keep it **fixed for the whole year**, so
the months stay comparable. Change it only at the annual review, and log any change here.

**How to run it (monthly, same week each month)**
1. Run each prompt in a fresh, logged-out or incognito session, from the Philippines where the
   engine allows it.
2. Use these engines: Google (AI Overview or AI Mode), ChatGPT with search, Gemini, Perplexity,
   Microsoft Copilot and Claude.
3. Log each prompt/engine pair in the tracking sheet. Record whether Premier was mentioned (Y/N)
   and cited with a link (Y/N, and which URL), whether it was described accurately (Y/N, with a
   note), the competitors or sources named, and the date.
4. AI Visibility Score = prompts where Premier is mentioned by **at least one** engine, out of 30.
   Also report the mentions per engine.
